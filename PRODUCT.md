# Product

## Register

product

## Users
Developers building AI agents on Solana, crypto-native builders, Web3 founders. These are power users who value security, technical depth, and a premium "command center" feel.

## Product Purpose
Leashd provides a secure, policy-enforced vault for autonomous agents. Owners can monitor agent spending, configure on-chain policies (limits, allowlists), and use an emergency kill switch to freeze activity.

## Brand Personality
Serious infrastructure, not a toy. Security-forward and technically sophisticated. Editorial, premium, and dark. Think: Vercel meets Phantom meets a security dashboard.

## Anti-references
- Generic purple-to-blue gradients
- Gray text on colored backgrounds
- Rounded-square icon tiles above headings
- Gradient text
- Card-in-card nesting
- Shadow soup

## Design Principles
1. **Editorial Authority**: Use serif italic uppercase for headings to command attention and feel like a high-end publication.
2. **Technical Sophistication**: Monospace for all crypto data and addresses to signal precision.
3. **Security-First Clarity**: Immediate, unambiguous feedback on the vault's state (Frozen vs. Active) and policy constraints.
4. **Spatial Rhythm**: Generous, purposeful spacing that avoids clutter and hierarchy through size and weight rather than boxes.

## Accessibility & Inclusion
- High contrast for critical actions (Kill Switch).
- Clear focus states and keyboard navigability for the terminal-like experience.
